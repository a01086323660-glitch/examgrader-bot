# بوت تصحيح الامتحانات 📝

المعلم بيبعت سلم التصحيح، بعدين صور أوراق الطلاب، والبوت بيقرأ الاسم والإجابات بنموذج ذكاء اصطناعي بيشوف الصور، بيصحح كل سؤال، وبيطلع ملف CSV بأسماء الطلاب وعلاماتهم.

## التشغيل (مجاني وصحيح)
هذا بوت بايثون يحتاج عملية **دائمة** (مو Cloudflare Workers).

### أسهل مجاني: جهازك
1. بايثون 3.9+ ثم: `pip install -r requirements.txt`
2. انسخ `.env.example` إلى `.env` واملأ التوكن ومفتاح Gemini
3. شغّل: `python bot.py` أو على ويندوز: `.\run.ps1` (يعيد التشغيل تلقائياً)
4. أبقِ الجهاز/النافذة شغّالة وقت الاستخدام

### استضافة سحابية مجانية (عملية دائمة)
**لا تستخدم Cloudflare Workers / Render النائم.** هذا البوت يحتاج يبقى شغال 24/7.

#### الخيار الأسهل: Fly.io
1. حساب على https://fly.io وتثبيت `flyctl`
2. جهّز `.env` ثم من مجلد المشروع:
   `.\deploy-fly.ps1`
3. راقب: `fly logs -a examgrader-bot`  
ملاحظة: الطبقة المجانية محدودة وقد تتغير — راقب رصيدك.

#### الأكثر ثباتاً مجاناً: Oracle Cloud Always Free
1. أنشئ VM مجاني (Ubuntu) وثبّت Docker
2. ارفع المشروع + `.env`
3. `docker build -t examgrader .`
4. `docker run -d --env-file .env -v examdata:/data --restart unless-stopped examgrader`

للتجربة: `python -m unittest discover -s tests`

## تحضير درس
1. `/newlesson` ثم أرسل نص/صور الدرس ثم `/done`
2. أجب أسئلة البوت القصيرة (الناقص فقط)
3. راجع المسودة ثم `/ok` — يرسل **PDF عربي احترافي** جاهز للطباعة
   (يتطلب: `pip install -r requirements.txt`)

## الاستخدام (تصحيح أوراق — صف ~20)
1. `/newexam` وابعت السلم (نص/صور، صفحة أو أكثر) ثم `/done` ثم `/ok`
2. اختر الوضع: `/mode_one` ورقة ورقة، أو `/mode_batch` طابور دفعة.
   ثم ابعت الصور. **ورقة متعددة الصفحات = ألبوم**.
3. `/report` تقرير الصف. راجع المعلّمة ⚠️ بـ `/next_review` ثم `/ok_paper`
4. `/finalize` يصدّر CSV **نهائي معتمد** فقط إذا ما بقي أوراق للمراجعة.
   `/csv` = مسودة فقط (مع تحذير).

أوامر: `/queue` `/stop_queue` `/papers` `/review` `/show 3` `/fix 3 2 1.5` `/name 3 اسم` `/ok_paper 3` `/delete 3` `/exams` `/use 2`

## كيف بيضمن الدقة
- مرورين تصحيح لكل ورقة (GRADE_PASSES=2). أي اختلاف بالاسم أو بعلامة سؤال، أو ثقة أقل من 0.75، بتتعلّم الورقة ⚠️ للمراجعة.
- الجمع والتحقق بالكود: العلامة ما بتزيد عن علامة السؤال، والسؤال الناقص بياخد صفر ومعلّم، والمجموع بيحسبه البوت مو النموذج.
- الـCSV فيه عمود "يحتاج مراجعة" وملاحظات. الورقة المعلّمة لازم المعلم يشوفها قبل ما يعتمد النتيجة.
- مهم: ما في ذكاء اصطناعي دقيق 100% بالخط اليدوي العربي. اعتبر النتيجة مسودة والمعلم هو المرجع، خصوصاً للأسئلة الكتابية والتصحيح الجزئي.
- نصيحة: خلي الصور واضحة وإضاءتها منيحة، وكل ورقة كاملة بالصورة.

## الخصوصية (مهم) 🔒
صور الأوراق وأسماء الطلاب بتنبعت لخدمة خارجية (Google أو OpenAI) ولتيليغرام. تأكد إنو هاد مسموح بمدرستك ومن أهالي الطلاب، وراجع سياسة الخدمة اللي اخترتها بخصوص استخدام البيانات (غالباً النسخة المدفوعة بتتعامل مع البيانات بشكل أحسن من المجانية، تأكد من الموقع). البيانات بتتخزن محلياً بملف SQLite (`examgrader.db`) على جهازك، فاحذف الأوراق (`/delete`) أو الملف لما ما تعود تحتاجها. استخدم `ALLOWED_USER_IDS` حتى يشتغل البوت لحسابك بس.

## حدود
- البوت بيصحح وبيشتغل ورقة ورقة (التصحيح بيأخذ ثواني، وبهالوقت البوت ما بيرد على غيرك). مناسب لمعلم واحد أو عدد قليل.
- ما بيحفظ الصور، بس النتائج والإجابات اللي قرأها.
- تنبيه: كل ورقة بتكلف طلبين للنموذج (مرورين) + صور. بتقدر تخفضها لمرور واحد بـ GRADE_PASSES=1 بس الدقة بتنقص.
- الشغل الدائم: جهاز أو سيرفر بيضل شغال، ولازم تحمي المفاتيح (ما تحطها بالكود أو بـ GitHub).
